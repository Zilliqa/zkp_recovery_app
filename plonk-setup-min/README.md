# PLONK setup — minimal circuit

Produces the PLONK proving key used by `../plonk-prover-min`. PLONK's setup is **universal**
(no per-circuit ceremony) — the powers-of-tau is all you need. Because the minimal circuit is
~4.5× smaller than the full one, this needs only **2²¹** powers-of-tau (not 2²³) and the key/RAM
are far more manageable than the full-circuit PLONK setup.

## Measured (this circuit, 2²¹, snarkjs 0.7.6)
- setup: **~11 min, ~14 GB peak**, key **3.7 GB**
- test prove: **~20 min, ~15 GB peak**, verifies `OK!`

## Repo vs large files
Only the small files are committed: `run-plonk-min.sh`, `input.json`, `vk.json`,
`verifier.sol`, this README, `.gitignore`, and `circuit_js/` (the minimal witness generator).
The large binaries are **git-ignored** and obtained separately:
- **`pot.ptau`** (~2.3 GB) — the canonical Hermez `powersOfTau28_hez_final_21.ptau` (verify with
  `snarkjs powersoftau verify`).
- **`circuit.r1cs`** (~101 MB) — compile the minimal `circuit.circom` (circom 2.2.3 + the pinned
  includes: 0xPARC circom-ecdsa @ d87eb70, circomlib 2.0.2, Electron-Labs sha512 @ be9f01d), or
  download from the bucket.
- **`circuit_plonk.zkey`** (3.7 GB) — regenerated by `run-plonk-min.sh`, or downloaded from the
  external bucket (GCS): `curl -L -o circuit_plonk.zkey https://storage.googleapis.com/bkt-p-zkproof-files-001/plonk/circuit_final.zkey`.

## Run it
```bash
# needs circuit.r1cs + pot.ptau in this folder (see above)
./run-plonk-min.sh
```
It runs: `plonk setup` → export `vk.json` + `verifier.sol` → generate a witness → `plonk prove`
→ `plonk verify`, timing the setup and prove. The resulting `circuit_plonk.zkey` is what you
upload for `plonk-prover-min` (rename to `circuit_final.zkey` there).

## Files
- `run-plonk-min.sh` — the setup + measured test-prove script.
- `input.json` — throwaway test input (BIP-39 all-zero vector, account 0).
- `circuit_js/` — minimal-circuit witness generator (wasm).
- `vk.json`, `verifier.sol` — setup outputs (PLONK verification key + `verifyProof(uint256[24],uint256[3])` verifier).
